Sistema de Estacionamento
Sistema para controle e gerenciamento de vagas e veículos em estacionamentos.

Tecnologias Utilizadas
Python (Lógica principal em main.py)
SQLite (Banco de dados em database.db)
HTML / CSS (Arquivos estáticos na pasta static/)

Como Executar o Projeto
Clonar o repositório
Instalar as dependências do arquivo requirements.txt
Executar o arquivo main.py
